<Callout title="Vertragsnotizen">
  <ul>
    <li>
      Event-Erstellung erlaubt nur die Initialzustände `draft` und `proposed`.
      Nutzer mit `event:create` landen standardmäßig in `draft`, Nutzer mit
      reinem Vorschlagsrecht in `proposed`.
    </li>
    <li>
      Event-Detailantworten liefern `availableTransitions`, berechnet aus den
      Rollen des aufrufenden Nutzers.
    </li>
    <li>
      Die Agent-Routen sind jetzt Teil der öffentlichen API und benötigen
      `agent:suggestions`.
    </li>
    <li>
      Aufgabenupdates laufen aktuell vollständig über `task:complete`, also
      auch dann, wenn nur Metadaten statt des Status geändert werden.
    </li>
  </ul>
