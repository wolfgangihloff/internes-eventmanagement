## Workflow-Empfehlung für neue Epics

1. **PRD lesen und Plan erstellen** — Claude Code Plan-Mode nutzen, um Architekturentscheidungen, Schema-Änderungen und API-Erweiterungen vorab zu klären.
2. **AGENT.md aktualisieren** — Neue Konventionen oder Domain-Regeln sofort festhalten.
3. **Schema zuerst** — Drizzle-Schema anlegen, Migration pushen, dann Services und Routes bauen.
4. **Backend komplett, dann Frontend** — API-Endpoints fertig testen, bevor die UI gebaut wird. Das vermeidet Ping-Pong zwischen Front- und Backend.
5. **Checks als Gate** — Nach jedem Schritt: `npx tsc --noEmit && CI=1 npx vitest run && npx eslint src/`. Erst weiter, wenn alles grün ist.
6. **Storybook-Doku mitziehen** — Neue Features in den relevanten MDX-Seiten dokumentieren.

<Callout title="Kernregel für Agentic Coding">
