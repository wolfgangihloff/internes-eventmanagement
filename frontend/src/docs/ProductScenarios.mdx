## Szenario 5: Dynamische Checklisten und Aufgabenplanung

**Beispielaufgaben:** Tickets buchen, Hotel buchen, internen Kalendereintrag erstellen, externen Termineintrag erstellen, Standmaterial vorbereiten, Nachbericht schreiben.
